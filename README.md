# หลักสูตร วศ.บ. วิศวกรรมซอฟต์แวร์ มฟล. ฉบับ 2564 และ 2569

เอกสารนำเสนอหลักสูตรวิศวกรรมศาสตรบัณฑิต สาขาวิชาวิศวกรรมซอฟต์แวร์ สำนักวิชาเทคโนโลยีดิจิทัลประยุกต์ มหาวิทยาลัยแม่ฟ้าหลวง สำหรับผู้มีส่วนได้เสีย

เปิดดู: https://prascymj.github.io/se-curriculum-2564-2569/
